HookChat Documentation

A guide to configuring and connecting your n8n AI webhook assistants

1. Overview

HookChat is a clean, modern web user interface designed to easily test, debug, and interact with your n8n webhook-based AI agents in real-time.

HookChat allows you to manage up to 5 different webhook assistants simultaneously. All configurations and chat logs are stored directly in your browser's LocalStorage. This means your private webhook URLs and chat histories are 100% private and never shared with any external database or third-party servers.

2. Step-by-Step Setup Guide

Follow these steps to configure your HookChat dashboard:

Step 1: Open HookChat

Open the HookChat website URL in your web browser.

Step 2: Add an Assistant

In the top-left corner of the sidebar, click the + (Add Webhook) button. In the modal that appears, enter:

  • Assistant Name: Name for your bot (e.g., Support Bot).
  • Webhook URL: Paste the Production Webhook URL generated by your n8n workflow.

Step 3: Start Chatting

Click OPEN CHAT on your new assistant's card in the sidebar. Type your message in the chat bar at the bottom and click the Send (➤) button or press Enter.

Step 4: Webhook Actions

  • Show/Hide URL: Click the 👁 (Eye) icon to toggle between masked (••••) and raw text mode.
  • Delete Assistant: Click the 🗑 (Trash) icon to delete a webhook and all its messages.
  • Clear Chat: Click the CLEAR CHAT button in the top-right header to wipe the message history.

3. n8n Webhook Configuration

To make n8n communicate correctly with HookChat, design your n8n Workflow with the following structure:

A. Webhook Node Settings

  • HTTP Method: POST
  • Path: Choose a custom path (e.g., hookchat-assistant)
  • Response Mode: On Received / Respond to Webhook
  • Response Data: All Entry Data (or construct a custom response payload)

B. Request Body Payload

HookChat sends the user's message inside the request body as JSON with the key chatInput:

{
  "chatInput": "Hello, how can you help me today?"
}

In your n8n workflow (e.g., in an AI Agent or Code node), retrieve the user's message using:

{{ $json.body.chatInput }}

C. Response Payload

HookChat expects your n8n workflow to return a JSON response containing either output or message. For example:

{
  "output": "This is the AI assistant's reply message!"
}

If your workflow returns a different format, HookChat will display the raw JSON as a string.

4. CORS Configuration (Critical)

Since HookChat runs inside a web browser, the browser will block requests to your n8n instance unless n8n allows Cross-Origin Resource Sharing (CORS).

How to fix CORS on n8n:

If your n8n instance is self-hosted, you must set the following environment variables in your n8n server settings before running:

# Enforce settings configuration
N8N_ENFORCE_SETTINGS_FILE_FOR_USERS=true
N8N_CROSS_ORIGIN_OPENER_POLICY=same-origin

# Allow CORS requests from the browser
N8N_DISABLE_CORS=false

If you host HookChat on a specific domain, ensure you allow requests from that origin inside your hosting environment or reverse proxy (like Nginx/Cloudflare).

5. Data Privacy & Storage

  • Where is data saved? Everything is stored inside your browser's local sandbox memory (localStorage).
  • Does it survive restarts? Yes. Restarting your device or closing the browser will NOT delete your saved webhooks.
  • What clears the data?
    1. Manually clicking "Delete" or "Clear Chat" in the UI.
    2. Clearing browser cookies and website site data.
    3. Using Incognito/Private windows (data deletes automatically when the window is closed).

6. Troubleshooting FAQ

Q: Why do I get a "Failed to reach webhook" error?

  1. CORS Blocked: Open your browser console (F12 -> Console). If you see a red CORS error, apply the steps in CORS Configuration.
  2. Invalid URL: Make sure you copy/pasted the Production URL, not the test URL. Test URLs expire after 120 seconds in n8n.
  3. No Network: Ensure your device has an active internet connection and your n8n instance is online and reachable.
